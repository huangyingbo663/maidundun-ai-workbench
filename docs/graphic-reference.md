# 小红书实拍与参考图文

用自己的商品照片和当前公开资料替换内容。喜欢简单直接地看商品，选01；想借鉴一篇参考的翻页顺序，选02。两种都交完整篇，不只做封面。

## 01｜实拍 A/B 图文

完整操作卡、素材清单、提示词、检查与失败恢复见[方法01：小红书实拍图文](方法01-小红书实拍图文.md)。A 是组合与价格浏览，B 是每款一页慢慢看；它们使用真实照片，保留商品原形和标签。走心主题另看[方法03](方法03-实拍与走心文案.md)。

## 02｜六模板参考图文

**想得到的样子：** 通过清楚的页序，帮助读者选口味、看预算、理解购物到使用，或收藏多款清单。

### 先选一种结构

|结构|示范页序|最低输入|
|---|---|---|
|T1 大图口味选择|组合封面＋三款大图，共四页|三款可核事实及清楚大图|
|T2 预算两款组合|合计封面＋两款详情，共三页|两款当前单价、单位、数量|
|T3 购物到真实使用|进店、选择、产品、比较、使用、结果、收尾|同款选购和实际处理/使用素材|
|T4 九宫格合集|九格总览后分组展开和收尾|九款逐款身份及素材|
|T5 十款完整合集|总览、十款详情、手持展示和收尾|十款完整资料，不只一张拼图|
|T6 手持包装对照|第一款手持/包装、第二款手持/包装、对照|同款外观与包装身份明确|

这些页数是实做结构的示范，不是平台要求。改变数量时，重新设计整篇页序并检查每页，不能只改封面数字。

### 输入与步骤

1. 提供完整参考或选一个结构；用[内容研究雷达](research-radar.md)核全页、标题正文和来源。记录每页让人继续翻的理由。
2. 收集自己的组合、单品、包装、场景照片；T3 另要真实拿取、拆开或使用结果。没有使用素材就做选购变体，别编已经吃过。
3. 建商品事实表：名称、价格、单位、可用表述、来源与核查日期。缺克重就省略，不由商品名猜成分。
4. 建两张映射：参考页功能→自己的页；自己的页→照片/商品/动作/允许表述。不同之处说明为什么改。
5. 先写整篇标题、正文和每页短句，再排版。每页一个重点，正文补充选择条件，避免把图上字抄一遍。
6. 用 HTML/CSS＋浏览器截图，或你熟悉的排版工具制作。本次实测图页为1200×1600；商品与文字分层，不让文字遮断面、包装或动作。字体须有相应使用条件。
7. 图片、页序清单、标题正文同时保存；先检查文件和尺寸，再逐页实际看图与手机缩略阅读。修订另存新版本。

**AI 摄影可选分支：** 只有实拍无法表达且明确允许虚构的生活情境才考虑。用真实产品作外观参考，先做一张小样，看手、接触关系、商品形状、假字与标签。实拍、既有 AI 图、本次新生成分别标记；商品断面、含馅量、大小不能由生成图证明。最终文字用排版工具制作，保留“AI 情境示意”。

### 可复制提示词

> 我要用自己的【商品与照片】做【T1—T6结构】。请先拆完整参考的页功能，给“参考功能→自有素材→真实事实→改编理由”表。按实际资料完成整篇标题、正文、页序和每页短句，不编使用经历、评分或优惠。优先实拍，缺结果镜头明确指出；AI 情境单列且不能改造商品事实。采用适合手机阅读的统一尺寸，完整渲染并逐页看图。交所有图片、文案、可编辑版式、来源清单、提示词和修订记录，不自动发布。

### 完成标准与常见修复

- 全篇页数与清单一致，单品、包装、金额和单位一一对应。
- 每个页面有明确作用，不以几十张重复图凑合集；T3 的结果确实拍到。
- 所有字能读，图与正文不冲突，真实商品没有被重画成别款。
- 缺图先查素材，不能网上找相似品补；错产品换真实图，不只换标签。
- 文本溢出先缩短或重排，不能关闭检查；总数变了同时改页序与清单。
- 来源有矛盾先隔离，对外只采用已核事实；输出目录已存在则新版本保存。

**实际范围：** 六结构、七套53页实际渲染，购物到使用做了两种不同真实输入。AI 情境新图也实际做过，图文路线共享该代表图，不重复计为两次生成。没有证明每一模板均完成独立新手复用；这些本机结果不等于新电脑安装、当前平台可发布或传播效果通过。原制作程序与素材未全量放入公开仓库，按卡复用时需由执行者选可用工具建立自己的工程。
