# 把一块台牌交给制作方

设计得到认可后，制作方还要知道实际裁多大、哪些线要切、哪些颜色要印。下面这张虚构的“材料领取处”台牌，用一个矩形把交付步骤走一遍。所需工具为能设置毫米画板、管理图层并导出矢量文件的绘图软件，以及能查看页面尺寸的阅读器。

## 从四个数开始

| 案例输入 | 填好的制作要求 |
| --- | --- |
| 成品外边界 | 宽 180 mm、高 120 mm，直角矩形 |
| 本次约定的出血 | 四边各 2 mm，背景色延伸至出血边界 |
| 本次约定的文字安全距离 | 重要文字内缩成品边界至少 6 mm |
| 正面内容与裁切 | 只印“材料领取处”和“请按桌号取一份”；沿外矩形切一圈，无镂空 |

这些数值属于练习。开工前向实物使用者核对摆放方向、完整外形和安装方式，向制作方索取本项目的出血、颜色及刀线要求，然后替换表中相应项目。

## 做出四件交付物

1. 建立 184 × 124 mm 的画板。以画板左上角为同一原点，将裁切矩形放在 (2, 2)，对角为 (182, 122)。从成品边再向内量 6 mm，文字安全框左上为 (8, 8)，右下为 (176, 116)。背景铺满整张画板。
2. 在**可编辑母稿**中保留文字、背景和裁切路径三个可单独选择的层。按制作方约定生成**印刷稿**，只导出会印出的画面。若需要转曲，在交付副本上处理，母稿保留可改的文字。
3. 用相同画板、方向和原点导出**刀线稿**，只显示成品外缘的一条闭合路径。将它与印刷稿叠在一起看四边是否各留 2 mm，关闭刀线层再看一遍印画。把尺寸、数量、镂空及出血写在制作说明里。
4. 由这版母稿另导出**正面预览**，供使用者认字、看方向。复核者分别打开印刷与刀线文件，查看页面和裁切对象的毫米数，再勾掉预览中的标题、副标题、方向三个检查项。交付时标清版本、哪个文件可以改字、哪个文件用于切割。材质、色差和实际安装效果留给打样确认。

**换一组数复做。** 把成品宽度改为 200 mm，其余约定不变。新版画板应为 204 × 124 mm，刀线路径仍是一条，宽应为 200 mm。若预览变宽而刀线仍宽 180 mm，回到新版母稿，重新导出同一版的印刷与刀线，两份一起复核。

**可复制提示词**

> 请按我提供的成品宽高、出血和安全距离，列出画板尺寸、裁切框、安全框及各自坐标。分别写出设计者、制作者和看预览的人要打开什么文件，给我三项可实际测量的验收动作。缺少的工艺条件列为待确认。
