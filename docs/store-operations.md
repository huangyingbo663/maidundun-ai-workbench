# 门店经营与营销

门店缺货、核销和营销复盘，常常各有一张表。先选你今天要做的判断。每个入口都有虚构样例、预期结果和可复制的提示词，工具可在自己的电脑上离线运行。

| 我想知道 | 打开哪里 | 拿到什么 |
| --- | --- | --- |
| 门店低于筛选线，冷库还能提哪些货？ | [冷库提货工具](../examples/stock-pick/README.md) | 候选、待核、筛除三栏清单；实际提货量由现场确认 |
| 这周核销了几次？这周卖出的券兑现了多少？ | [团购券核销对账](../examples/voucher-review/README.md) | 按发生日的事件数、同一支付批次截至期末的券状态与两个核销率 |
| 两种套餐共用一种商品，可以各卖多少？ | [团购组合与共享库存](store-bundle-planning.md) | 共同占用量、履约上限和调整方案 |
| 这条视频适合给哪款团购引流？ | [推广候选核对](store-video-fit.md) | 画面、文案、规格与实际可兑现内容的逐项判断 |
| 顾客买促销品时，还买了些什么？ | [同票加购复盘](store-promo-baskets.md) | 同票有付费加购的比例、对应金额和待核小票 |

**第一次用。** 直接打开[一份已算好的提货清单](../examples/stock-pick/expected.txt)或[一份核销结果](../examples/voucher-review/expected.json)。若想复算，下载本项目后从对应入口复制命令。换输入时使用自己的本地私有目录，避免把真实经营表加入公开仓库。第三至第五个入口只需纸笔或表格就能复算。

这些工具按你提供的快照提出判断。门店、仓库、券平台、投放后台及账务系统的操作由各自的业务流程完成。本项目的示例可在断网环境运行。
