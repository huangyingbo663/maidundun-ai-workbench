# 办公与重复任务自动化

手头是一批刚拷完的文件、一份已有时间码的字幕，或一张需要把数字录准确的扫描表？从对应任务开始。两个工具都只用 Python 3.12 或更高版本的标准库，下载后可在本地离线运行。另有两份可手工练习的方法。

| 我今天要做什么 | 打开哪里 | 拿到什么 |
| --- | --- | --- |
| 判断副本是否少文件、多文件或内容有变 | [复制后核对工具](../examples/copy-check/README.md) | 逐路径列出相同、缺失、多出及内容不同的报告 |
| 把已有 SRT 字幕变成方便标注的逐段核对稿 | [字幕转核对稿](../examples/subtitle-notes/README.md) | 带段号、起止时间和原行文的纯文本 |
| 检查 OCR 把哪一行、哪一个单位识别错了 | [纸表数字回核练习](office-ocr-review.md) | 一份能逐项追到原图位置的纠正记录 |
| 打印或其他重复作业中途断了，决定是否重试 | [重复请求与回执核对](office-repeat-jobs.md) | 一张能分清“成功、待核、可重试”的记录表 |

**想先看结果？** 打开[复制核对报告](../examples/copy-check/expected.json)中的 `summary`，或直接阅读[字幕核对稿成品](../examples/subtitle-notes/expected.txt)。两个入口都有完整命令、原创输入和换输入的预期结果。OCR 练习和重复请求练习只需浏览器或纸笔。
