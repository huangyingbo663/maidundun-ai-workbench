# 两条雷达：找值得学的内容，把它变成自己的方法

先用你有权查看和研究的公开链接、自有文件或合法参考开始。爆款雷达负责发现与筛选内容；内容研究雷达负责提取、拆解、适配和入库。它们不是联系博主、投流或代发账号的工具，也不是第17种内容风格。

## 入口一：爆款雷达

**适合：** 还不知道下一条拍什么，想找到有观看价值、自己也有条件做的参考。

**输入：** 受众、具体场景、想回答的问题、产品或动作、现有拍摄条件、研究平台与时间范围。可以给一个种子作品，也可以从关键词开始。

**步骤与工具：**

1. 把研究问题拆成“人群＋处境＋观看所得＋动作/产品”的关键词。可以跨行业找结构，不只找同城同行。
2. 用实际可访问的平台搜索、公开网页或合法读取接口找作品。保存查询词、时间、结果链接和可见字段。访问失败保留结果，不反复盲试，也不假装搜到了。
3. 从作品找作者，再看同作者普通作品和高互动作品，或补同题对照。明星身份、突发事件或特殊场景可能不可迁移。
4. 保留平台原指标、单位和观察时间。播放缺失写未知，点赞不代播放；含义未核的零值不能当真实零播放。
5. 判断是否有明确停留理由、信息或情绪兑现，以及我们能否用自己的素材做到。分别标“有高互动证据”“只有风格学习价值”“来源待核”。不要用统一点赞门槛筛所有平台。
6. 每个入选项给一个具体学习理由、一个不照搬部分和下一步需要补的证据。交给内容研究雷达，不直接当正式模板。

可复制提示词：

> 我想为【受众】做【场景/问题】的内容，已有【素材与拍摄条件】，目标平台是【平台】。请定向寻找值得学习的作品，记录实际搜索范围、出处、发布时间、观察日期和平台原指标，补同账号或同题对照。缺失指标写未知，无法读全的作品标局部。按观看价值、可迁移性和素材条件给入选/排除理由。不要把作者当合作对象，不联系、不发布，不承诺流量。已有合格模板可直接提出复用。

**验收：** 候选能回到实际作品或明确的局部索引；高互动与风格判断分开；至少有一组可解释的对照；能说清下一步要完整研究哪条、为什么。

**失败恢复：** 只有搜索摘要就保留线索状态；无法取得全页或完整视频，停止完整拆解判断；样本少就收窄结论，不虚构长期有效。读取工具或平台换了，先验证一条真实可读输入，再批量研究。

## 入口二：内容研究雷达

**适合：** 已有完整参考，想知道它具体怎样写、拍、剪、配声，并形成自己的可复用模板。

**输入：** 参考出处、允许的研究用途、完整视频或图文页、平台文字，以及自己的商品事实、素材和目标风格。

**步骤与工具：**

1. **入库。** 用文件探测工具检查视频时长、音轨、旋转或图文页数；计算 SHA-256，去重但保留来源与观察日期。缺页就标局部，不把目录里有文件当完整。
2. **分栏提取。** ASR（语音转文字）只记实际声音；OCR（识别图片文字）只记屏幕文字；平台标题/正文、评论另列。保留原始机器稿、校订稿和修改依据。
3. **完整核看。** 图文按全页顺序看；视频先顺序覆盖全片，再对关键切点和动作补帧。记录实际观看范围与时间精度。抽帧、播放器可解码、ASR 输出都不能代替完整听审。
4. **逐镜/逐页拆解。** 每一行写来源时码或页号、实际看到/听到什么、观看功能、文字作用、动作、声音、转折和下一页/镜的关系。将观察事实与效果推测分栏。
5. **提炼结构。** 按下方八维总结固定功能、可换内容、最低素材需求、不适用情形和验证假设。不是把第三方原句换几个名词。
6. **映射自有输入。** 建“参考功能→自己的画面/事实→改动理由”表；缺动作转拍摄卡，缺事实删掉承诺。商品、经历、价格和处理方式不能来自参考作者。
7. **制作与检查。** 选择[对应风格](content-paths.md)，完成自有整篇/整片。检查的是新作品，不用参考热度替它签通过。
8. **入库与复用。** 保存模板版本、来源摘要、适用范围、实际产物、检查和失败。用不同真实输入复做，才能扩大复用范围。未发布的反馈字段保持未知。

工具按功能选择：合法读取工具负责发现；FFmpeg/ffprobe 负责探测与取样；ASR、OCR 分别提取声音和画面文字；表格或 Markdown 保存拆解；图文渲染器或剪辑软件执行适配。公开文档不承诺这些工具已在你的电脑安装，也不附带登录账号或所有平台读取通路。

### 拆解的八个维度

|维度|需要回答的问题|
|---|---|
|人群与处境|谁在什么时刻看，想解决什么或获得什么？|
|开头停留理由|第一句话/画面给出什么悬念、反差或具体信息？|
|信息与故事顺序|开始、变化、转折、兑现、结尾怎样连接？|
|文案与表达|每句承担什么作用，句长、停顿、重音怎样服务意思？|
|画面与动作|主体多大、怎样运动、动作是否完整、字放在哪里？|
|声音与节奏|原声、音乐、音效各在何时进入、减弱或停止？|
|产品与情绪兑现|产品为什么此时出现，观众实际获得了什么？|
|可迁移与差异|哪些功能必留，哪些必须换成自己的事实，什么条件下不适用？|

可复制提示词：

> 请研究我提供的完整参考，先检查可读范围，分别整理语音、屏幕字、平台文案和评论，保留机器稿与疑点。按八维逐镜或逐页拆解，每个关键判断能回到时码/页号。再提炼固定结构、可变项、素材与声音条件，并用我的真实素材做适配表。只输出原创总结和我能使用的提示词，不复制第三方整篇文案。缺完整音频、页图或事实时标明缺口，不编补。完成自有作品后再记录试作状态，不能因参考高赞就称模板已经有效。

### 可直接填写的模板卡

~~~text
模板名称 / 版本 / 对应方法：
目标受众 / 观看所得：
来源出处 / 观察日期 / 完整或局部：
实际指标及其性质（没有就写未知）：
关键来源时码或页号：
固定功能 / 可换内容 / 不适用条件：
每镜或每页：功能 → 自有素材 → 事实依据 → 差异理由
声音条件 / 音源用途与署名要求：
原创建议提示词：
本次试作产物 / 实际检查范围：
失败与修复 / 下次从哪里继续：
发布反馈（未发生则未知）：
~~~

**验收：** 原声与屏幕字幕没有混为一谈；整页/全片覆盖范围真实；关键结论可追溯；模板有固定/可变项和失败条件；新作品有自己的事实和素材；研究材料的可读性与成品可用性分开。

## 实际验证到哪里

本次定向发现真实执行过，但新发现线索有仅能读搜索信息、拿不到完整原片的情况，未升级为完整参考。历史合法保存的图文与视频被重新核读，并非把旧链接列表冒称新采集。快手读取没有本次实跑证据。

完整九页图文已分栏提取、校订与适配，购物到使用结构做过两种不同真实输入；另有新 AI 上下文完成来源到新图文的限定复用。OCR 某页零候选不证明没有字，仍需看原图。

视频来源已补全片视觉逐镜、动作与屏幕字幕追溯，自有产品有两种完整适配。但机器转录只覆盖参考前段，后段可见字幕不能直接当口播补齐；完整声音、疑词、音乐身份与实际声音落点仍待核。视频来源链没有因此被标成全部通过。

## 常见修复

|问题|处理|
|---|---|
|ASR 只到前半段，后面还有字幕|保留原稿；核后段音频，不抄屏幕字伪造转录|
|图片价格与平台正文矛盾|同时保留，标冲突；自有作品只用自己的当前事实|
|OCR 说没字，但眼睛看得到|记录识别未覆盖，人工校读并注明依据；不删除原失败|
|同一参考重复出现|按媒体指纹去重，保留不同日期的指标快照|
|模板只能换标题，画面和情境都不变|重新设计受众问题、动作或商品用途，说明实质差异|
|不知道参考用了什么歌|标未知，不凭气氛猜曲名；另选有使用依据的声音|

原片、完整转录、原文案和抓取响应保留在你自己的研究环境。公开分享使用原创结构总结与自有示例；拿到文件不等于取得再分发权。实际发布时再核当前平台与音源使用条件。
