# 视频参考复刻：节奏复刻与动作迁移

参考完整作品，使用自己的素材。04 学习逐句逐镜的观看功能；13 让生成角色跟随合法动作参考。两者使用的工具、证据和验收不同，剪辑成功不能证明动作模型可用。

## 04｜逐句逐镜复刻

**输入：** 完整参考、自有原片、当前商品事实、允许使用的原声/配音/音乐，以及要保留的语气和结尾。缺关键动作先去[方法05](filming-remake.md)。

**步骤与工具：**

1. 先用[研究雷达](research-radar.md)把语音、屏幕字、画面与音乐分栏。只拿到转录稿不能判断镜头和配乐。
2. 做逐镜表：参考时间→信息/情绪/动作→自己的源片区间→输出位置→声音落点→改编理由。保留悬念和兑现，换掉他人的人物、场所和事实。
3. 按当前事实核商品身份、单价、单位、数量与合计；在素材中检查每次拿取是不是对应产品，别凭包装颜色判断。
4. 用剪辑软件或 FFmpeg 编排。画面段与声音段分开声明；B-roll（辅助实拍）换画面时不要重复切断同一句话。变速记录实际源区间消耗，不把示例速度当所有片子的默认值。
5. 配音先保存真实音频和实际时码，再做字幕。音乐、音效、语音分轨；统一混成连续 PCM 后最后编码，避免每句重复编码带来断裂。
6. 导出完整片，检查每次商品切换前后、字幕出现/消失、金额兑现和结尾；再完整听声音。封面和正文对应当前版本。

可复制提示词：

> 请逐句逐镜拆解这条参考，记录信息、情绪、动作、声音、转折和时长，再映射到我提供的自有素材。保留吸引人看下去的功能，缺镜头或事实就指出，不用别款商品凑完整。完成新视频、准确字幕、双比例封面和发布文案，保留来源时间表、工程、声音清单与修订。技术检查和实际完整听看分别记录，不承诺与参考流量相同，不自动发布。

**验收：** 每句/镜头能回到来源；画面、字幕、声音没有串款；所有算式与事实一致；核心悬念被兑现；完整片、工程、字幕、封面与文案齐全。

**修复经验：** 价格字幕即使区间看似正确，也可能因帧与字幕时间精度不同在切点残留。实际看切前/切后帧，必要时留短暂空隙，不能只看每秒截图。开头提前泄露反转就换合法区间；结尾多拿一件就截在真实完成处；错音不能只改字幕掩盖。

**实际范围：** 新完整片和价格字幕修正已做，另有新 AI 上下文重新组织素材的完整作品及限定复核。完整听感、用户采用与发布效果单独记录；不宣称任意复杂特效、贴纸和参考都能一键复刻。

## 13｜AI 动作迁移

**输入：** 有权使用的完整动作视频、人物参考、场景参考、身份使用条件和希望保留的动作关键点。自己的肖像用于一次制作，不自动等于允许公开原图和模型输入。

**步骤与工具：**

1. 用 ffprobe 看时长、帧率、旋转、画幅和音轨，完整看动作。优先选主体不出画、遮挡少的简短手势。
2. 写可检查的动作条件：手从哪里移动到哪里、先后顺序、头部朝向、衣服与身份不变。把最难的交叠动作作为首样重点。
3. 选当前确实支持该输入的动作迁移服务或本机模型。先核输入规格、认证、使用条件，再做最小真实样；本次准备采用过五秒竖屏无声输入，但不能把准备规格当所有模型通用参数。
4. 执行者保存请求指纹和任务状态。提交后未知先查原任务；已接受则继续同一任务，不能因等待超时重复生成。
5. 成功后完整下载，核文件、SHA-256和可解码性，再对齐动作关键点逐段看人物、手指、衣服、背景及标识。
6. 明确问题才修对应镜头。贴脸、局部遮盖不能破坏跟踪和动作；不自然就保留失败并重选方案。
7. 合格后再做封面和文案，注明 AI 动作演绎。参考的音乐不随动作自动取得使用权。

可复制提示词：

> 用我有权使用的【人物/动作/场景】做动作迁移。先完整看参考，列动作起止、遮挡和身份保持条件，再选最小可验证片段。固定人物外观和衣服，保留【关键动作顺序】，双手完整入画，场景文字不能被改造。先说明可执行工具与实际未验证部分，真实首样合格后才扩大。保存任务回执和失败；未知任务先查状态，不重复提交。交完整动作对照、成片和限制，不把静态图或普通剪辑冒充模型生成。

**验收：** 完整动态输出、真实任务/本机运行记录、人物和动作逐段对照、场景关系与使用条件明确。静音是设计选择时如实写静音，不称原声保真。

**实际范围与恢复：** 有历史采用经验；当前新例已准备自有动作、人物、场景、提示词和规格，但新生成、下载及完整动态检查尚未做。本机既有嘴部驱动样片不能代身体动作迁移。服务不可用或没有合格输入时停在准备状态，不把普通 FFmpeg 剪片或测试色条称动作迁移成品。
