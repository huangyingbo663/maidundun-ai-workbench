# 方法01：用自己的实拍制作小红书图文

把照片换成你自己拍摄、拥有使用权的商品与场景照片，再把商品名称、价格、单位和文字换成你当前核实的信息，就能复用这套方法。保留原图，所有裁切、提亮和排版都在副本上做；不要沿用别人的商品数据，也不要让AI重新画出食品外观。

> 本卡根据两套不同输入的实拍图文制作记录整理。第一次使用时，请用自己的产品信息核对每一页。

## 先选你想做的风格

|风格|适合表达什么|完整页序|
|---|---|---|
|A：带你逛一圈|展示门店、组合和不同选择，帮助读者比较|固定6页：场景开门 → 真实组合 → 逐款清单 → 按偏好拆分与合计 → 包装外观 → 门店收尾|
|B：一款一小段|让读者慢慢看每款商品，读自然、简短的选择建议|组合封面＋每款1页；选2—4款，共3—5页|

A选3—4款商品。B每页集中讲一款。整套内容要有顺序，不能只做一张好看的封面。

## 准备哪些实拍和事实

|材料|怎么准备|不够时怎么办|
|---|---|---|
|组合照片|商品同时入镜，能分清选了哪些；背景尽量干净|补拍能看清完整组合的一张|
|每款完整外观|每款至少有清楚、无遮挡的完整照片；包装信息尽量可读|补该款照片，不让AI补画商品或切面|
|包装或标签细节|用于展示实际外观；文字和当前事实一致|标签过期或说法未核实，改用真实包装图，不修改照片上的价格和卖点|
|环境照片|自己的门店、柜台或陈列场景|A版式缺环境图就明确补拍，或改选材料齐备的B版式|
|公开事实表|名称、当前价格、计价单位、信息核对日期；克重和其他说法只填已核实项|不知道就留空，文案同步省略，不猜数值|
|本次表达目标|希望读者看懂哪种选择、哪几款商品|先写一句主题，避免每页讲不同的事|

照片里有无关人物、联系方式或其他私人信息时，先更换取景或处理好再使用。不要把成本、利润、采购资料或后台截图放进面向顾客的页面。组合照片多出一款商品时，要讲清楚本篇重点介绍哪些，不能让读者误以为所有商品都包含在报价里。

## 可复制给AI的原创提示词

把方括号里的内容换成自己的信息，并提供照片和事实表：

> 我想用自己的实拍做一套小红书图文，主题是［本次想让读者看懂的选择］，商品是［商品名称］。请先看我提供的照片和当前公开事实表，判断选A“逛店比较”还是B“逐款介绍”，说明缺哪张照片或哪项事实；已提供的材料请直接整理。
>
> 只使用这些真实照片中的商品。每款名称、价格、单位与事实表一致；没有核实的克重、口感、营养或活动不要补写，不编试吃经历、顾客评价、评分和优惠。组合总价请逐项计算并列出依据。
>
> 先给完整页序与逐页短文案，标题不超过20字。B若采用六行纸卡版式，每款正文明确分成六行。保留原图，另存排版版本；只能做自然提亮和合理裁切，不重画食品、包装或标签。
>
> 完成后给全套图片、标题、正文、话题和一个方便逐页查看的入口。请逐页检查文字、商品、裁切与合计；发现错误自行修订并保留旧版，说明哪些检查已实际做过。先交我看，不发布、不购买服务。

## 从照片到整套图文

1. **核事实，定页数。** 选A或B，确定商品名单与每页任务。把价格、单位和核对日期放在同一份事实表里；缺信息时省略对应说法。新发布前重新核价，旧截图不是实时库存或价格证明。
2. **整理照片副本。** 先纠正照片方向，再裁切。保留完整商品和必要包装文字，不拉伸、不补画。自然提亮只为让原图好看清，不能把商品颜色、纹理或大小改成另一种样子。
3. **写每页文案。** 先讲选择情境，再给真实名称、份量或价格，最后给读者自主选择。短评要能从已核事实得到支持。A的组合、拆分和合计要相互对应；B纸卡正文按六行排，不靠缩成小字塞满页面。
4. **排成完整套图。** 本方法采用1200×1600竖图。标题、商品主体和短文案保持明确层次，同一套的字体、留白与提亮方式统一。主要字体使用自己有权使用的版本；换字体会改变换行，需重新检查。
5. **检查后导出。** 自动化流程的顺序是预检输入 → 渲染到新目录 → 验证结果；手工排版也按相同顺序核对。每次修订另存版本，保留失败记录和旧图。
6. **逐页看真实导出图。** 不只看编辑界面或程序日志。检查全尺寸、手机预览和缩小后的样子：标题是否一眼能读、产品是否完整、文字是否遮挡主体、包装有没有被误裁、首尾页是否接得上。
7. **交付完整材料。** 全套JPG、标题、正文、话题、原图来源记录、可编辑工程以及检查说明一起保留。可以制作一个本地“打开看”页面，按页序呈现图片与配套文案。发布是另一步，不能把导出成功写成已发布。

## 自动化执行者需要保留什么

这套方法已有Python、Pillow、Playwright与浏览器渲染的本地实现经验。自动化复用还需要输入模板、渲染脚本、验证脚本与字体；它们是否随公开仓库提供，应以实际发布清单为准。**本页提供制作方法，不声称仅凭这一个文档就能在新电脑上一键运行。** 没有配套程序时，可以按上面的页序用已有排版工具完成。

输入工程至少保留：

- **照片登记：** 文件名、原件出处、SHA256、方向纠正及提亮参数。更换照片后重新核来源，不能沿用旧校验值。
- **商品配置：** 名称、价格、单位、详情主图、小图和包装图的裁切位置。裁切坐标按方向纠正后的原图像素记录为“左、上、宽、高”，不能越界。
- **内容配置：** A/B类型、商品名单、组合照片、标题、导语、逐页文字，以及A的拆分与结尾。采用既有B纸卡时保留六行正文要求。
- **批次清单：** 内容版本、套数、A/B数量、页数及离线整理顺序。整理顺序不是定时发布任务；数量不符时修清单，不能删除验证限制。
- **输出记录：** 实际导出版本、图片校验值、自动检查结果、逐页查看记录与修订理由。

本方法不需要生成食品图片，也没有固定配乐。静态轮播可不配音乐；如后续另选配乐，需单独确定来源和使用条件，不能因为参考帖有音乐就写“同款”。

## 做到什么程度算完成

- A/B页数正确，全部页面都已导出，图片与标题、正文、话题一致。
- 商品身份、包装与照片一致；公开名称、价格、单位来自本次事实表，合计算对。
- 没有星级残留、假试吃、虚构好评、未核优惠或营养承诺。
- 每页文字清楚，商品主体完整，标签未被错误裁去；手机预览也能读。
- 没有成本、后台或私人资料；原图、可编辑工程与版本记录可追溯。
- 已查看实际输出，而不只是程序返回成功；尚未检查的项目明确写“待检查”。

## 已知验证范围

原制作环境已有一套A六页、一套B三页的实际输出，共九张1200×1600 JPG，并完成渲染、自动检查及逐页视觉查看。还对历史批次做过文件兼容回归；兼容回归不算新内容创作，也不能代替本次商品事实核对。

这证明既有材料与原制作环境中的方法可以运行。它不证明新电脑安装、任意照片和任意字体都已通过，也不证明发布后会获得流量、到店或成交。本版公开说明未重新运行制作，公开包的独立安装与复用检查另行记录。

## 常见问题怎么修

|现象|处理办法|
|---|---|
|输出目录已存在|换新版本目录，保留旧结果，不删除失败记录后重跑|
|照片校验值变化|重新核实是否换了原图或误改文件；不要直接把新校验值填进去凑通过|
|面包被裁掉、裁切越界|先看纠正方向后的原图，再改副本裁切；不拉伸或生成补齐|
|套数、页数或商品数量不符|按真实制作计划修内容和批次清单，不关闭检查|
|文字溢出或太小|缩短句子、明确分行，或改合适版式；重新看实际导出图|
|旧标签、价签不可信|改用当前真实包装或外观照片，文案只写已核事实|
|程序通过但看起来不对|保留报告，逐页定位问题后另版修订；退出码不能代替人看|
|组合照片和文字范围不一致|补拍准确组合，或在文字中明确本篇选取范围，不制造套餐误解|
