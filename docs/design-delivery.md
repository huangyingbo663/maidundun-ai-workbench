# 设计、文档与培训交付

先确定谁来打开文件、对方拿到后要做什么。教同事练习、给客户确认金额、送印一张海报，各自需要的内容和核对方法都不同。

| 今天要交什么 | 从这里开始 | 第一眼核什么 |
| --- | --- | --- |
| 给学员练习、给讲师验收的两份资料 | [离线培训任务单](../examples/training-sheet/README.md) | 学员只拿练习；讲师保留答案和换题条件 |
| 给客户确认的品名、数量和价格 | [销售确认单生成工具](../examples/sales-sheet/README.md) | 末行、货款小计、运费及版本是否写清 |
| 供设计方与制作方核对的平面物料 | [平面物料送印交接](delivery-print-handoff.md) | 成品尺寸、出血、刀线和打样回执 |
| 一次培训中学员、讲师各自用哪一版 | [培训分版与验收](delivery-training-versions.md) | 新学员能否独立完成，实际学员文件是否含答案 |
| 给客户可填的表，再交一份阅读版 | [对客表单与阅读版](delivery-customer-form.md) | 输入位置、可见字段和新增末行公式是否一致 |

**先看成品。** 下载仓库 ZIP 并解压，双击 `examples/sales-sheet/expected.html` 或 `examples/training-sheet/expected.html`，用浏览器查看和打印预览。培训示例成品是讲师完整包；发送给学员时按工具说明选择 `--audience learner` 另行生成。两个工具只需 Python 标准库，示例全部虚构，无需在线服务。

现场打样、真实客户确认与课堂学习成效应由各自的使用者验收。方法卡提供可复做的样例和核对方法。
