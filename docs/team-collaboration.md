# 数字员工与项目协作

活动指引卡写好了，谁看过这一版？接班人该去改文字、等尺寸，还是去现场看摆放？这套练习用一张虚构的周末活动指引卡走完派工、交稿和接班。工具只读本地文件，三个人也可以在普通对话和文本文件里照着做。

| --- | --- | --- |
| 第一次组织人和 AI 协作 | [跟做一次完整接力](team-relay.md) | 三个角色的提示词、能交给下一人的任务卡 |

| 让助手在下一项工作里沿用这套做法 | [协作分工与接班 Skill](../skills/team-handoff/SKILL.md) | 可以复制给助手的完整工作指令 |

## 先做一遍

1. **负责人看条件。** 打开[练习事实](../examples/work-brief/materials/event-facts.md)，确认能公开写在指引卡上的三步。打开[示例派工板](../examples/work-brief/expected.md)，找到可以开始写文案的人，再看排版依赖哪一项。
2. **写者交实物。** 打开[指引卡交稿](../examples/handoff-check/artifacts/guide.md)，以第一次来参加活动的读者身份逐行读。哪怕只改一个地点，也请让复核者看改过的这一版。
3. **接班人分清下一步。** 将[独立复核回执](../examples/handoff-check/reviews/guide.json)和[交接结果](../examples/handoff-check/expected.json)并排打开。找出已经复核的文案、需要场地同事核实的一件事，以及还缺输入的排版任务。只要现场尚未核实，就在交接里留下负责人与观察方法。

没有 Python 时可以手工跟做以上三步。想亲自验证“为什么改一个字就要重看”，请下载整个项目，照[接力练习](team-relay.md)用 Python 3.12 或更新版本在副本里试一遍。全程可离线完成。

## 怎样换到自己的项目

先选一项明天就能验的交付，例如一张上岗练习卡。把示例中的三条活动事实换成你已核实的操作要求，再把“现场看指引卡”改成实际使用场景，例如请新同事独自完成一次练习。在复核人实际试过前，将该项留作待办。涉及顾客、账号或后台数据时，公开讨论使用虚构样本，原始材料保存在有访问权限的项目中。
