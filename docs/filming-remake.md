# 拆解、拍摄、复刻

用真实动作兑现视频里的承诺。缺素材时选05，把参考变成现场看得懂的拍摄卡；已经有同款连续素材时选06，直接做购物到使用的完整作品。

## 05｜把参考变成能照着拍的动作卡

**输入：** 喜欢的完整参考、现有原片、现场能拍的人/物/地方、产品事实和拍摄限制。先查已有素材，不为了执行流程重拍。

**步骤与工具：**

1. 用[内容研究雷达](research-radar.md)提炼参考的观看功能：观众为何停下、等待什么、结尾得到什么。
2. 每镜写一个实际动作，至少包括对象、谁做、机位、起态、过程、终态、声音和前后余量。将“有质感”改成可执行的动作说明。
3. 按现场路径合拍：同一个地方、产品或机位尽量一起完成，剪辑顺序之后再定。把确实缺的动作合并成一张清单。
4. 手机竖拍可作为起点，擦镜头、握稳或固定，正常速度完整做动作，前后各留一至两秒。主体和包装正面清楚，别在动作完成前停机。
5. 收回完整原片，保留原名和原件。用文件清单与哈希去重；先按标签、连续动作和真实资料核身份，再记录可用源区间。
6. 回传验收分“可用、可裁修、需补动作、身份待核”。说明具体缺口；换产品或改承诺要有依据，不能默默用相似品补。
7. 按04、06或10完成整条剪辑，交拍摄卡→原片→最终镜头的映射，再补封面、正文和完整检查。

可照拍的清单示例：

|镜头|现场动作|回传检查|
|---|---|---|
|认品|包装正面和对应价签各清楚停留|品名、单位和价格确实对应|
|选择|同款从货柜拿到篮或台面，完整拍到|没换款，手未挡关键标签|
|处理|完整拆袋；按该品真实条件处理或直接掰开|动作起止与实际处理条件可核|
|结果|断面靠近停留，若试吃则真实拍入口|结果真的出现，不用另一款替代|
|整理可选|固定机位拍空篮、逐件摆入、完成后留尾|变化和数量能看清，终态不截断|

可复制提示词：

> 按方法05把这条参考变成我能拍的动作卡。先检查已有原片，只有真正缺的动作才要求补拍。每镜写对象、机位、起态、完整动作、终态、声音和前后余量，按现场位置合并清单。素材回来后保留原件，核商品与完整动作，给具体不足及修法，再完成整片、字幕、封面与文案。不要把演示当真实成交，不编顾客行为，不自动发布。

**验收：** 拍摄者知道做什么和何时停；制作人能凭原片找到对应动作；缺口明确；整片的承诺有画面兑现。历史已有真实操作者照任务回传、发现不足并修正，本轮又用原片做了新作品；没有陌生真人首次拿卡拍摄的验证，不把 AI 新上下文复做等同于真人现场试拍。

**失败恢复：** 只有满篮就不能剪成完整空到满；身份不清先核标签与连续动作；缺动作只补对应一镜；现场没发生的成交、评价和收入不靠表演补成纪实。

## 06｜购物过程接单品

**想得到的样子：** 先给一个选择问题，再把选中的同款商品实际打开，让观众看到结果。

**输入：** 明确产品、当前公开事实、同款选择/拿取/拆袋/处理/结果的原片。不是每条都要加热；有哪种真实动作就承诺哪种结果。

**步骤与工具：**

1. 定一个问题，如“在这个预算里怎么选”或“打开是什么样”。没有真实预算就不用金额作钩子。
2. 按标签和连续动作核同款身份。将每段源文件、源时码、输出位置、用途、字幕依据列成动作账。
3. 排成问题→选购→拿取→实际处理→结果。可以压缩等待，但不得把几秒剪辑当实际加热时长。
4. 对比维度一致，价格有单位与数量。处理参数只有匹配本款、设备和初始状态时才写；缺参数就说明依本品说明处理，不猜数字。
5. 用剪辑软件或 FFmpeg 制作，产品画面优先完整。现场声音、解说、音乐各有来源；要静音就明确，不从表情编味觉评价。
6. 完整看商品连续性、处理顺序和结果；在切换处看价签与字幕，避免相邻商品标签混入。金额和单位按语义放在一起。
7. 完整听审后交视频、字幕、双比例封面、文案、动作映射和工程。没有拍过分享给家人，结尾就不编家人反馈。

可复制提示词：

> 用我的实拍做一条“选择问题→同款取用→真实处理→可见结果”的完整视频。先核每段都是同一产品，当前价格、单位和处理条件有来源。缺参数不猜，缺动作转最小补拍卡。压缩等待时不能把片长当处理时长。声音与字幕忠实于实际素材，演示不冒充顾客成交。完成整片、封面、文案、源区间映射和检查，修订另存。

**验收：** 选的是最后展示的那款；结果真的拍到；比较与预算可复算；处理做法有对应条件；画面、字幕和文案不额外承诺。

**实际范围与修复：** 已有两个不同产品、动作与结果的完整实例；其中一例包含拆袋、设备处理、断面和入口，另一例只证明选择与掰开。该风格另有独立新作品复做。发现错款或相邻价签就换真实区间，不能用正确字幕盖住错误画面。没有验证通用精确复热处方、所有音轨听感、平台效果或新人首次拍摄。
