# 实拍与走心文案

适合一张有动作的照片。例如掰开面包、把一份早餐装袋，或把最后一块分给同桌的人。如果照片主要在展示好几款商品和价格，先看[实拍图文](方法01-小红书实拍图文.md)。

## 准备什么

选一张有权使用的自有实拍。写下三个事实：画面里是谁或哪只手、正在做什么、产品有哪些已经核实的特征。再写一句“我希望谁读到它”。画面里没有出现的经历、关系或顾客评价，不能当成真实故事。

## 怎样写

1. 从可见的动作写起。先用一句普通话描述照片，再挑出最能让目标读者想起自己生活的细节。
2. 把感受落到一个小动作上。例如画面确实是把面包分成两半，可以试写“分你一半，也给自己留一半”。这是示例句，使用时按自己的照片修改。
3. 图上只留读一遍就懂的短句，避开手、包装名称和产品主体。正文补一层意思或提一个自然的问题，避免把图上文字原样再念一次。
4. 按要发布的平台分别准备标题、正文和图片顺序。使用配乐时核实来源，实际试听文字出现的节奏和音量；先发静态图文也可以。

## 可以复制给 AI 的提示词

> 用我提供的实拍做一篇给【读者】的图文。先告诉我你在照片里确实看到了什么，再围绕一个小动作写三条图上短句。每条配一句说明，让我知道它和这张图怎么对应。选最贴切的一条，给出可直接排到图上的文字、标题和正文。商品信息只用我的事实表，资料不足的地方留空。最后按手机缩略图和原图各检查一次，列出还要我核实的内容。

## 交稿前检查

手机上第一眼能看清动作和短句吗？一句文案换成另一张无关照片也成立吗？如果成立，就回到照片补一个具体细节。产品名称与包装相符吗？读者会把想象当作门店事实吗？把无法核实的内容删掉，再通读一次。
