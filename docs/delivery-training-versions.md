# 给学员练习，给讲师验收

同一堂课可以交两种材料。学员需要拿到任务、输入和交付要求，讲师需要拿到答案、评分依据和追问。本页含参考答案，供备课者使用。可以用本地文字编辑器分别制作两份文档。以下是一道独立的虚构练习。

## 先用一题跑通

**目标**　根据借用记录算出活动结束时每种物品还缺几件，并写出应向谁核问。把下面的小表和任务文字放进学员版。

| 组别 | 物品 | 发出件数 | 已归还件数 |
| --- | --- | ---: | ---: |
| 甲组 | 方形拼片 | 7 | 5 |
| 乙组 | 圆形拼片 | 4 | 4 |
| 丙组 | 条形拼片 | 3 | 未记录 |

**学员版交付要求**　交一张三行表，列出各组、未归还件数与后续动作，并注明未知值怎样处理。仅使用练习里已给的记录。可以手算，也可以用本地表格。

**讲师版验收依据**　甲组为 2 件，请甲组核对剩余数量；乙组为 0 件，可标记已归还；丙组数量待核，先请丙组补齐归还记录。评分看三项可观察结果：两个已知数量是否算对、未知数是否保留、追问是否指到对应组。任一缺项都能指出要返工的具体一行。

## 分成两个文件再复核

1. 在内部题目底稿写清题号、输入、目标、验收依据。把任务与输入写入一个新的学员文件，把同题号、答案、常见误判写入另一个讲师文件。两份文件都标版本。学员文件里只存学员需要看的内容。
2. 用学员实际会用的阅读器单独打开学员文件，逐行核输入和任务。检查备注、折叠区、批注及文档属性，避免把讲师答案随学员资料发出。讲师打开自己的版本，对照题号逐项复算。
3. 做一次修订练习。将甲组归还数从 5 改为 6，保留已认可的首版，另存学员、讲师两个 v2。新版答案应为 1、0、待核。若讲师仍判甲组为 2，检查讲师答案或仍在用的旧链接；修正后再让同事用新版学员材料独立答一遍。
4. 交接说明列出“学员先打开哪份、讲师拿哪份、该做哪道题、交回什么”。如果培训使用纸面，在打印预览看跨页的表头和空白答题区。记录实际看过的文件；课堂学会率需另收学员答卷统计。

**使用离线工具。** [任务单生成器](../examples/training-sheet/README.md)附有另一道可直接试做的题。默认输出含讲师验收内容，由讲师保留。按下列命令生成独立学员页，交付前打开它，搜索一条只属于讲师的参考答案；预期零命中。把核对过的学员文件单独发给学员。

~~~sh
python examples/training-sheet/generate.py --input examples/training-sheet/demo.json --audience learner --output learner-v1.html
~~~

**可复制提示词**

> 请根据我给的虚构任务做一份学员练习稿和一份讲师验收稿，分别列出文件名、题号和版本。学员稿保留完成任务所需的事实和交付格式，讲师稿把参考答案、常见错误与返工动作逐行对应。请用一项改动计算第二版答案，标出需要同步更新的材料。
