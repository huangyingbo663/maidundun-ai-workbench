# 把已有 SRT 转成带时间码的核对稿

整理录音或视频的字幕后，校对人需要知道每句话原来出现在哪一秒。本工具从现成字幕取得段号、起止时间与逐行原文，生成可直接打开的 UTF-8 文本。全程离线，只用 Python 3.12 或更新版本的标准库。

## 第一次使用

1. 在项目根目录打开终端。先看[虚构的 SRT 示例](demo.txt)中的第 15 段，它跨过了整一小时。
2. 运行下方命令。示例的扩展名是 `.txt`，内容为标准 SRT 文本；自己使用时可以直接传入 `.srt` 文件。
3. 双击生成的 `subtitle-notes.txt`，与[预期结果](expected.txt)对照。应有 3 段，第 14 段的两行正文均保留，第 15 段的结束时间为 `01:00:02,050`。这份演示没有配套录音。

~~~sh
python -B -X utf8 examples/subtitle-notes/convert.py --input examples/subtitle-notes/demo.txt --output subtitle-notes.txt
~~~

## 换自己的字幕

从字幕编辑器导出 UTF-8 SRT，复制到自己的工作目录，把命令中的输入路径换成该副本，输出文件名换成新版本。每段依次填段号、起止时间、正文；两段之间留一个空行。可从摘录原段号开始，段号须递增且允许跳号。时间格式为小时、分钟、秒和三位毫秒，逗号分隔毫秒。UTF-8 BOM、Windows 与 Unix 换行均可读取。

校对人用播放器跳到对应时间，核听措辞后在另一份校订稿记录“段号、原文、修订建议、依据”。正文里的分行、空格、发言者标注及字幕样式标记按输入保留。起始时间相同或两人同时讲话造成的时间重叠也会保留，前提是各段起始时间按非递减顺序排列。这个步骤仅整理已有文字。声音是否听准、画面里的字是否识别正确，分别回到原媒体或图像核实。

**换条件自测。** 在输入副本里，把第 15 段的“左栏”改为“第一栏”，结束时间改为 `01:00:02,850`。输出新稿，只有这一段的文字和结束时间应变动。再将第 16 段的开始时间改为 `00:58:00,000`，程序应指出倒序所在行并停止。修正副本或重新从字幕编辑器导出，再另取输出名。已有输出会被保留。

**输入边界。** 编码错误、缺少空行或正文、无效时间、零时长、倒序段号和起始时间均应检查来源；诊断中的行号指向输入文本。含位置参数的时间行、WebVTT、ASS 请先导出基本 SRT。建议先用自己的播放器抽查头、中、尾三段，特别是跨小时和多人交叠处。

**可复制提示词。** “请对这份可公开的字幕核对稿逐段列出需复听的词，保留原段号、起止时间和原句。将建议放在单独一列；缺少声音依据的写待听。先检查跨小时标记和多行字幕。”
