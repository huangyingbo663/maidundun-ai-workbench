# 把一项工作做成学员任务单

给新同事一份能自己动手的练习，再给另一位同事一页可以逐条判断的验收标准。示例任务是把虚构的展览改期记录写成访客通知。讲师可改同一份 JSON，生成一份浏览器可读、适合 A4 打印的 HTML。

## 先做一次

1. 下载并解压项目，双击本目录的 [expected.html](expected.html)。也可以先读[虚构材料与检查项](demo.json)。
2. 学员只读第一部分，依据三条给定材料写出一份访客通知及一份内部核对清单。纸笔、文本编辑器均可。
3. 另一位同事拿到提交件后，再打开“独立验收”部分。在记录里写明哪一句通过，哪一句缺事实依据，然后把“换一组条件”的题目交给学员复做。示例的换题只改变集合点，学员应保留两个版本。

在仓库根目录打开终端，使用 Python 3.12 或更新版本运行：

~~~sh
python -B -X utf8 examples/training-sheet/generate.py --input examples/training-sheet/demo.json --output lesson-sheet-v1.html
~~~

双击新文件，与随包的 HTML 对照。默认 `--audience full` 供讲师和复核者使用。发给学员时另生成一份：

~~~sh
python -B -X utf8 examples/training-sheet/generate.py --input examples/training-sheet/demo.json --output learner-v1.html --audience learner
~~~

只分发 `learner-v1.html`。其中仅写入学员任务，验收项、复核者的换题与预期结果都从文件中省去；完整 JSON 和默认版本留给讲师。讲师可单独口述换题条件，请学员换条件重做。设计练习时也要检查公开给学员的材料和提示词，避免在其中自行填入讲师答案。

示例打印预览采用 A4 纵向，完整版的练习与复核分别起页，学员版只保留练习。长材料会自然续页，实际页数取决于字体和打印设置。网页中的文字可以复制，手写或另存文本均可记录答案。

## 换成自己的任务

复制 JSON 到自己的私有目录，确定一位学员、一个工作情境、一种可观察的交付物。保留字段名，修改以下各项。列表中的每一项独立写为一段文字。

| 字段 | 填什么 |
| --- | --- |
| `title`、`version`、`audience` | 任务名称、版本和谁来做 |
| `objective` | 让读者知道什么动作或交付证明学会了 |
| `materials` | 可核实的事实与可供复做的材料。若含待核信息，要写明状态 |
| `steps`、`submission` | 学员依次做什么、完成后具体交什么 |
| `prompt` | 可复制给 AI 的练习提示词；写进任务单后仍可手工完成 |
| `checks` | 由他人打开提交件就能判断的条件，注明需查看的位置或内容 |
| `transfer.variation`、`transfer.expected` | 给学员换什么条件，复核人应看到什么变化、哪些约束仍成立 |

例如改练“写出图书捐赠回执”。给出三本书的虚构交接行，要求只为接收成功的两本出具回执，将一本破损待核的书列入待核清单。复核者核书名、接收数量和待核项。换题把一本已接收书改成待核，回执应只剩一本。修改时把材料、练习、验收和换题四处一起改，另取输出名。

## 检查与修订

- 缺字段、空白段落、空列表、重复 JSON 字段或字段拼写不符时，命令返回失败。先修输入副本，旧版本可以继续查看。HTML 文本按普通文字转义，输入中的尖括号、引号与 `&` 不会变成页面元素。
- 输出文件名已占用时换一个版本名重新运行。把私有资料与练习答案保存在仓库外的本机目录。示例只读给定的本地 JSON；不会提交表单或调用 AI。
- 确认交付时打开生成文件，查看宽屏、窄屏与打印预览。复核人换一组材料重新做，分别记录工具能生成页面、练习能完成、他人是否能验收。人员是否学会以实际提交件为准。

在仓库根目录可运行 `python -B -X utf8 -m unittest discover -s examples/training-sheet/tests` 重跑工具测试。
